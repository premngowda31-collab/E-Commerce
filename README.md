# E-Commerce Project

A modern, responsive e-commerce web application built with HTML, CSS, and JavaScript. This project provides a complete online shopping experience with product browsing, search functionality, shopping cart, and checkout capabilities.

## Features

- **Home Page** - Engaging landing page with featured products and promotions
- **Product Catalog** - Browse products by category with detailed product information
- **Product Details** - In-depth product pages with specifications and reviews
- **Search Functionality** - Quick search to find products by name or keyword
- **Shopping Cart** - Add/remove items and manage your cart
- **Checkout** - Secure checkout process for completing purchases
- **About Us** - Company information and mission statement
- **Responsive Design** - Mobile-friendly interface that works on all devices
- **Background Music** - Enhanced user experience with ambient background music

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/premngowda31-collab/E-Commerce.git
   cd E-Commerce
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server (e.g., Python, Node.js)

   **Using Python:**
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`
